## Valid fixture requirements (`tests/fixtures/validCase.ts`)

The `makeValidCase()` builder must produce a valid `CaseFile` that:

- Has ≥2 suspects (R14 — at least one non-culprit)
- Has exactly 1 culprit (R2)
- Contains ≥1 `clue-presented` trigger, ≥1 `fact-confronted` trigger, ≥1 `contradiction-exposed` trigger (so all Trigger variant branches are reachable)
- The culprit's `alibi.breaksWhen` is present (R16)
- All knowledge sets satisfy three-tier semantics (R7–R9)

## Non-obligations (do NOT write these)

- Any "correct accusation" test (scoring belongs to engine)
- Any LLM eval, recorded-fixture replay, or wire payload scan (no LLM call sites in shared)
- Any network/DB test
